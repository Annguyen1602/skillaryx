# Contributing

Skillaryx is early-stage and the full product codebase is not currently public.

Useful contributions to this public repository include:
- documentation fixes
- safer permission patterns
- additional deterministic eval examples
- feedback on the public skill package model

Please do not submit:
- API keys or credentials
- private customer data
- unrestricted shell/network examples
- claims of integrations or partnerships that cannot be verified

For product or technical contact: founder@skillaryx.com
